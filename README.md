# Portfólio

Este repositório reúne projetos, estudos e registros de atividades em programação e cibersegurança.

## Estrutura

```text
.
├── Cybersecurity/
│   ├── README.md
│   └── TryHackMeLabs/
│       └── IntermediateNmap/
│           ├── README.md
│           └── Images/
└── Programming/
    └── preview.txt
```

### `Cybersecurity/`

Contém documentação de estudos e laboratórios de cibersegurança. O README desta pasta descreve a organização dos laboratórios. Cada laboratório tem sua própria pasta; por exemplo, `TryHackMeLabs/IntermediateNmap/` reúne a documentação do desafio Intermediate Nmap e as imagens usadas nela.

### `Programming/`

Área destinada a projetos e materiais de programação. Atualmente, contém `preview.txt`.

## Como consultar

Os arquivos README dentro de cada seção ou laboratório trazem os detalhes específicos daquele conteúdo. A estrutura pode crescer conforme novos projetos e registros forem adicionados.
